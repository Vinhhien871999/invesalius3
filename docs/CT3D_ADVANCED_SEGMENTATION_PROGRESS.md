**Blocking finding (30/09/2026, found during the E6 input-volume audit - NOT yet fixed)**: the plugin's world↔voxel conversions use the wrong spacing axis. `Slice().spacing` is **(x, y, z)** - proven by InVesalius's own code: DICOM import sets `spacing = xyspacing[0], xyspacing[1], zspacing` (`control.py:1300`, same at `:1180`), the `Slice.spacing` setter pairs it with `matrix.shape[::-1]` (`slice_.py:202`), and the axis-swap code swaps it accordingly (`slice_.py:2184-2189`); `converters.to_vtk()` passes it straight to `vtkImageData.SetSpacing()`. But `core/sync_2d3d.py` `world_to_voxel()`/`voxel_to_world()` (lines 124-146) and `interface/project_interface.py`'s identical pair divide the AXIAL (z) coordinate by `spacing[0]` (x) and the SAGITAL (x) coordinate by `spacing[2]` (z); their docstrings' claim that spacing is "index-aligned with matrix.shape" is false. Invisible when x and z spacing are equal (dataset `0801`: 0.977/0.977/1.0 mm, ~2% error); large on anisotropic data. Measured with real dataset `0051` geometry (108×512×512, spacing (0.4785, 0.4785, 1.5)): true volume bounds (VTK, same call as the surface pipeline) x 0-244.5 / z 0-160.5 mm vs plugin x 0-**766.5** / z 0-**51.2** mm; a mid-volume point maps to voxel **(107, 255, 81)** instead of ≈(53, 255, 255). **Affects**: C8 plane bounds (axial plane clamped to the bottom third, planes 3× too wide), 3D pick → 2D slice sync (since Phase 09 - also present in stable `ct3d-rc1`, which is not modified), E5A texture slice selection (textures from the wrong slice on anisotropic data - would confound E5-B/C/D/E), and any future E6 point prompt. **Not affected**: final surface, E4 preview mesh, E2/E3 (they pass `Slice().spacing` straight to VTK or use its product only). Several tests encode the wrong assumption (e.g. `test_coordinates.py`'s "(axial, coronal, sagital)" spacing, `test_preview_surface_mesh.py:157`'s "(1.5, 0.4785, 0.4785) real dataset 0051 spacing convention"). Recommended next step: a separate fix on this branch, before E5-B/C/D operator verification.
